# 🇨🇭 mint-app-interface

> Status: 🛠️ In Progress / Learning Web3 Frontend
> Author: MonoSwiss

A minimalist frontend interface for a Web3 Minting dApp. This is my educational repository for tracking progress in smart contract interaction and decentralized applications.

---

## 🚀 Features
- [ ] Connect Wallet button (Metamask / WalletConnect integration)
- [ ] Responsive UI for uploading metadata and images
- [ ] Dynamic Mint Counter connected to a testnet smart contract
- [ ] Gas estimation and network switch notification

## 🛠️ Tech Stack
- Frontend: HTML5, CSS3 (Swiss Design Grid), JavaScript
- Web3 Libraries: Ethers.js / Wagmi
